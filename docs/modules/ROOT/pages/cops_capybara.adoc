[#capybarachainedfind]
== Capybara/ChainedFind

|===
| Enabled by default | Safe | Supports autocorrection | Version Added | Version Changed

| Pending
| Yes
| Always
| <<next>>
| -
|===

Avoid chaining `find` methods and combine selectors.

Combining selectors into a single `find` call is more efficient than
chaining multiple `find` calls, as it reduces the number of DOM queries.

[#examples-capybarachainedfind]
=== Examples

[source,ruby]
----
# bad
page.find('#foo').find('.bar')
page.find('#foo').find('.bar').find('.baz')

# good
page.find('#foo .bar')
page.find('#foo .bar .baz')
----

[#capybarafindallfirst]
== Capybara/FindAllFirst

|===
| Enabled by default | Safe | Supports autocorrection | Version Added | Version Changed

| Enabled
| Yes
| Always (Unsafe)
| 2.22
| 3.0
|===

Enforces use of `first` instead of `all` with `first` or `[0]`.

[#safety-capybarafindallfirst]
=== Safety

This cop's autocorrection is unsafe because `all` returns a
`Capybara::Result` (an enumerable collection), while `first`
returns a single `Capybara::Node::Element`. Replacing `all`
with `first` may break code that depends on the return value
being a collection (e.g. calling `.each` on the result).

[#examples-capybarafindallfirst]
=== Examples

[source,ruby]
----
# bad
all('a').first
all('a')[0]
find('a', match: :first)
all('a', match: :first)

# good
first('a')
----

[#references-capybarafindallfirst]
=== References

* https://www.rubydoc.info/gems/rubocop-capybara/RuboCop/Cop/Capybara/FindAllFirst

[#capybaravisibilityoption]
== Capybara/VisibilityOption

|===
| Enabled by default | Safe | Supports autocorrection | Version Added | Version Changed

| Pending
| Yes
| Always
| <<next>>
| -
|===

Checks for boolean values passed to Capybara's `visible` option.

`visible: false` finds both visible and hidden elements, rather than
only hidden elements. Use `:all`, `:hidden` or `:visible` instead.
Only `true` is autocorrected, to `:visible`.

This cop targets Capybara's built-in selectors. Set `DefaultSelector`
to match `Capybara.default_selector`, or to `null` if it varies at
runtime. Queries using custom or unknown selectors are skipped.

[#examples-capybaravisibilityoption]
=== Examples

[source,ruby]
----
# bad
find('.menu', visible: true)
expect(page).to have_css('.menu', visible: false)

# good
find('.menu', visible: :visible)
find('.menu', visible: :all)
find('.menu', visible: :hidden)
----

[#defaultselector_-custom-capybaravisibilityoption]
==== DefaultSelector: custom

[source,ruby]
----
# bad
find(:css, '.menu', visible: true)

# good
find('.menu', visible: true)
----
